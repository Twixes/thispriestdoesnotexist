# NADA with the 24 clean-background portraits

2026-09-21. **A single ten-update feasibility smoke is worth considering if the factorial does not produce useful collars; a longer NADA run is not yet justified.** The new opportunity is the official image-guided variant: all24 reviewed portraits can define an unpaired target domain without latent inversion, exact target correspondence, clothing masks or source-face preservation. Those constraints were our safeguards, not user requirements. This is a narrower, concrete addition to `post-factorial-fallback-feasibility.md`, not a claim that NADA will beat diffusion or reach production quality. No implementation, model loading, training, installation or download was performed.

The [official README](https://github.com/rinongal/StyleGAN-nada/blob/main/README.md) supports target image sets as well as text. Its setup is Rosinality/CUDA, so our NVIDIA safetensors are **not** a drop-in checkpoint for its SG2 wrapper. Reimplement the small loss/wrapper around our already-tested native NVIDIA generator; do not convert weights merely to run an old CUDA stack. This preserves the single-G inference architecture. The [paper](https://arxiv.org/abs/2108.00946) supplies domain-adaptation evidence, not a demonstrated photoreal Roman-collar solution.

## Minimal proposed recipe

Use the unchanged native1024 source bundle `research/runs/inference-cpu/ffhq1024/baseline-bundle` (recorded weights SHA256 `f802061515460f211faee6a6ff60d8803f4aa15b26cdce0edc5bbef7d88aaa2d`) for both frozen source and student. Use constant noise and psi1. Freeze mapping, its moving average, noise buffers and source G. Initially open learned constant plus all17 synthesis convolution modules, including early4–32px blocks; freeze every ToRGB module. Their affine parameters and noise strengths belong to the convolution modules and remain trainable. This is a deliberate manual all-scale NADA-style choice, unlike the factorial's restricted64–1024 range.

The official manual default excludes mapping and ToRGB; its optional automatic selector optimizes W+ against a global text objective, ranks per-style-slot movement, then unfreezes corresponding layers. That selector introduces extra backward work and Rosinality-specific indexing. Do **not** copy its integer indices into NVIDIA blocks: NVIDIA's skip architecture shares W indices between ToRGB and the next block. Disable auto-selection for this small image-guided smoke; a later selector would need an explicit tested slot-to-module map. [Official generator wrapper and selector](https://github.com/rinongal/StyleGAN-nada/blob/main/ZSSGAN/model/ZSSGAN.py).

Define E(x) as a frozen CLIP image embedding normalized to unit L2 length. Compute a detached direction

`d = normalize(mean(E(target24)) − mean(E(source32)))`.

For a shared fresh z, use `Ldir = 1 − cosine(E(Gstudent(z)) − E(Gsource(z)), d)`, averaged over samples. Cache source/target features without gradients; preserve input gradients through the student CLIP branch. Use only this loss after initialization: no pixel reconstruction, protected-face term, source-D features, R1, PL or trained discriminator. This follows the official image-centroid direction and directional loss; CLIP parameters remain frozen. [Official CLIP loss](https://github.com/rinongal/StyleGAN-nada/blob/main/ZSSGAN/criteria/clip_loss.py).

For this proposed monochrome variant, apply the same differentiable grayscale-to-RGB transform to both generated branches and all source-centroid images. Use the accepted **whole-image**1024 derivatives in `research/data/plain-background24-whole-image`, not the affine/reflection crops. Then map GAN output [-1,1] to [0,1], differentiably bicubic/antialias-resize the complete square to224, and use CLIP mean `(0.48145466,0.4578275,0.40821073)` / std `(0.26862954,0.26130258,0.27577711)`. Never convert the trainable branch through PIL, uint8 or detach. Record this grayscale variant explicitly; preserve complete native outputs, with no output compositing or restoration.

**Initialization needs an explicit numerical decision.** Identical generators and shared constant noise make the first edit vector exactly zero. The upstream loss perturbs target pixels when its vector sum is zero, then divides by the edit norm. Copying that behavior is unsuitable as our numerical safeguard. Proposed deviation: update1 uses `1 − cosine(E(Gstudent(z)), mean(E(target24)))`; updates2–10 use the directional loss with norm denominators clamped to1e-6. Record edit-vector norms and abort on nonfinite gradients; epsilon alone must not be mistaken for a meaningful initial direction. This one-update bootstrap is our variant, not an official NADA recipe or proven optimum.

Use the official training script's actual Adam LR0.0016 and betas `(0, 0.99**0.8)` for the ten-update diagnostic, batch1 and no style mixing. The script obtains these from LR.002 and a retained4/5 lazy-reg ratio even though its training loop does no regularization; do not accidentally compensate twice. Its saved `g_ema` is the trainable generator state, not an additional EMA maintained by that loop. Our smoke should label outputs raw and add no new EMA. [Official training loop](https://github.com/rinongal/StyleGAN-nada/blob/main/ZSSGAN/train.py).

## Bounded discrimination test

If selected, run only ten actual updates, CPU1/FP32 first, with no concurrent heavy job, fresh free memory≥35%, a proposed12GiB process-RSS abort and20-minute total cap including feature preparation and previews. Do not infer an MPS bound from CPU RSS; an MPS version needs separate allocated/driver-memory measurement. Pin all24 images and32 existing FFHQ source identities before deriving centroids. Use ten fresh training latents and eight separate fixed unseen evaluation latents; preserve their actual z arrays. The source centroid bank is not a serving seed catalog.

Save complete native1024 source/student images at0/5/10, all eight evaluation outputs, source/CLIP/frozen-parameter hashes, selected parameter names, loss/edit norms, finite gradients, actual updates, runtime and peak memory. Compare tab shape, shirt/neck geometry, full facial anatomy, age/gender/headwear and variation. Identity or pose changes are allowed; smears and repeated faces are not. Check checkpoint reload without a second optimization trajectory. This is a plumbing and initial-direction test, not ten-update convergence evidence.

**Continue only on useful visual movement without facial degradation**, alongside finite, affordable backward. Lower directional loss alone is insufficient. ViT-B/32 sees only224px with32px patches: a tiny tab is weak supervision, and clean backgrounds may offer an easier way to improve similarity. If outputs merely darken clothes/backgrounds, masculinize faces, or move CLIP score while collar geometry remains absent, do not automatically extend to hundreds of updates or add losses. A neutral ten-update result is inconclusive about NADA generally but provides no evidence for spending days on this particular variant. The earlier diffusion feasibility option remains available.

No adult-only, bareheaded-only or subjective-hotness guarantee follows from domain adaptation. Serving would still need independently validated selection; training-time CLIP is not automatically such a validator. Existing NVIDIA and CLIP notices remain unchanged; NADA's MIT code license does not relicense source weights. This note neither promotes a model nor authorizes deployment.
