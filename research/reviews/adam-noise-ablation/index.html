What changes when learned noise offsets are reset?

Diagnostic, not a model candidate. This compares raw G at iteration 100 of the released-source convolution-layout probing control (source_flattened). No new training, Fisher estimation or main adaptation occurred in this ablation. Nothing here establishes production quality or server generation latency.

All four fixed latents are shown without filtering, repairs or selection. Each row contains the original FFHQ baseline and all three ablation arms. Click any image for its native 1024 × 1024 original. These source-population latents can include children, women and non-clergy; they are not a proposed priest catalog.

Zeroing an offset retains the original noise strength. It removes the learned additive change, not the pretrained coefficient or the fixed noise maps. The single-offset arm changes only b1024.conv0; the all-offset arm changes all 17 learned noise-strength offsets. All other checkpoint state is verified unchanged.

The unchanged raw arm reproduces the four archived checkpoint-100 PNGs byte for byte. Same latents; constant noise; truncation 1; FP32; unfused modulated convolution. The original FFHQ baseline is shown for context. Four fixed latents cannot establish generalization or unseen-latent diversity.
