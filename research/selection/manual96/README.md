# Manual visual eligibility annotations for 96 sources

`labels.json` retains one record for every original source: v1 indices 000–031 and batch2 indices 000–063. The extra v1 reproduction/calibration source is excluded so the set is exactly 96. All input files remain unchanged. Each row contains its source PNG SHA256, seed, review scope, seven requested eligibility labels, age/presentation components, and a short visual note. Manifest/contact hashes and annotation/code hashes provide provenance.

These are **single-reviewer Codex visual annotations**, not measurements or independently validated human ground truth. They were manually authored from original source portraits, without loading CLIP scores, model predictions, rankings, or previous source-selection JSON. The reviewer had seen some sources and clothing edits earlier; this is therefore not a blinded independent human study. Nothing in this annotation pass used an edited target as the label image.

Both complete original-PNG contact sheets were viewed during this pass. Fourteen portraits were additionally inspected natively in this pass; fifteen others had already been inspected natively by the same reviewer against these exact stored sources. Each record distinguishes those scopes. The remaining 67 are explicitly contact-only. Contact inspection is useful for obvious hats, other people, childlike appearance and broad framing, but insufficient to certify fine facial anatomy: those artifact labels generally remain uncertain.

The labels are `yes`, `no`, or `uncertain`. Adult appearance is conservative: 68 clearly adult, 17 age-uncertain, 11 clearly childlike. Numeric age and actual gender identity are not inferred. `apparent_adult_male` means clearly adult with masculine visual presentation for this project, not a factual identity claim. Headwear includes caps, hats, scarves, helmets, crowns and substantial head/hair ornaments. Extra people includes recognizable partial faces/bodies and crowds; ambiguous background shapes remain uncertain. Neck usability asks whether clerical clothing could fit without moving the face or changing the crop.

`hot_candidate` is a subjective face-aesthetic label for the requested calendar concept, separate from hats, people, neck and artifacts. It is not an objective attractiveness score. An appealing adult face with a hat or second person can still receive `yes` here while failing a separate eligibility criterion. No attractiveness assessment is performed for childlike, age-uncertain, or non-masculine/uncertain-presentation cases; `hot_assessment_performed=false` makes that explicit. For those records, `no` means not eligible for this adult-male project, not unattractive. Do not use this as a general beauty or demographic dataset.

There are 31 clearly adult masculine portraits, 11 subjective face-aesthetic candidates, and only **one** example (b2-055) passing the strict conjunction of adult-male=yes, hat=no, extra-people=no, usable-neck=yes, facial-concern=no, and hot-candidate=yes. That strict count reflects uncertainty and this small unfiltered batch, not a claim that only one portrait could ever be useful. Do not convert uncertain labels into negative ground truth or silently relax the gate to inflate yield.

For rejection-sampler research, report per-label agreement on adjudicated yes/no examples and keep uncertain rows separate. Contact-only anatomy labels need native review before being scored as negatives or positives. A second reviewer and a larger held-out sample would be needed for dependable classifier validation; the current set can expose obvious failure modes and guide bounded research. Do not fit and report evaluation accuracy on the same 96 records.

`annotations.tsv` contains the manually authored judgments. `build_labels.py` only validates completeness, attaches original hashes/seed provenance, and packages JSON; it does not import a model, run inference, or compute scores. The packaging check passed for all 96 records and all source hashes. `validation.log` contains counts and the JSON hash. No training manifest, image, active run, production sampler, or output was changed. This is not production approval.
