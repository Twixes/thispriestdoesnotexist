# Independent portrait candidates165–180

Sixteen separate built-in imagegen calls produced sixteen original1254×1254 PNGs. No references, edits, retries or collage crops were used. Every native original is retained unchanged as `165.png` through `180.png`; these are training candidates, not outputs of the locally trained generator.

`prompts.json` and the four `tool-results-*.json` files preserve exact prompts and tool-returned original paths. `manifest.json` records original/copy SHA256 equality, dimensions, channel checks and the hash-bound root selection. `technical-review.json` records native inspection of every image. `contact-256.png` is a labeled diagnostic montage only; it does not replace or modify originals. `build-manifest.py` reproduces the metadata/contact from originals and the separately saved root review.

All16 pass visual anatomy, bare-head and clerical-collar checks. All look monochrome but have slight numerical chroma (maximum RGB-channel differences8–14/255), so they are not strict grayscale until separately preprocessed. No preprocessing or active dataset change was performed here.
